## О проекте

В игре Rust ночью видимость падает практически до нуля. Традиционно игрокам приходилось сворачивать игру, открывать «Панель управления NVIDIA» или «AMD Adrenalin Software», вручную двигать ползунок гаммы до 1.5, а с наступлением дня повторять действие обратно.

Rust Gamma Pro решает эту проблему в один клик. Программа работает через аппаратную таблицу калибровки дисплея Windows (Hardware LUT через `SetDeviceGammaRamp`), позволяя переключать ночную и дневную гамму по одной кнопке прямо во время игры.

---

## Ключевые возможности

- **Мгновенное переключение:** Нажатие клавиши (по умолчанию `F11`) переключает гамму за 1 миллисекунду без задержек и лагов.
- **Безопасность от Easy Anti-Cheat (EAC):** Программа не внедряется в процесс игры, не читает память и не перехватывает графику DirectX. Античит к ней абсолютно равнодушен.
- **Автоопределение Rust:** Утилита сама находит запущенный процесс `RustClient.exe` и активирует хоткей только когда вы в игре.
- **Умный выбор монитора:** Гамма меняется только на том мониторе, где развёрнут Rust (например, игровой монитор AOC / 144Hz / 2K), не затрагивая второй экран с Discord или браузером.
- **Защита от сбоев (Fail-Safe):** При закрытии игры, вылете или перезагрузке ПК гамма автоматически сбрасывается в стандартные 1.00.
- **Поддержка любых видеокарт:** Одинаково работает на NVIDIA GeForce, AMD Radeon и Intel.
- **Звуковая индикация:** Высокий тон — включен режим ночи (1.5), низкий тон — стандартный режим (1.0).
- **Графическое окно настроек:** Ползунок гаммы (1.10 – 2.20), кнопка тестирования (2 сек), выбор горячей клавиши и автозапуск с Windows.
- **Двуязычный интерфейс:** Мгновенное переключение между русским и английским языками (RU / EN).
- **Минимальный вес:** Исполняемый файл весит ~180 КБ, потребляет 0.0% процессора и менее 10 МБ оперативной памяти.

## Безопасность и Easy Anti-Cheat (EAC)

Античит Easy Anti-Cheat банит за внедрение в память (DLL Injection), модификацию игровых файлов или макросы на отдачу мыши.

Rust Gamma Pro использует официальный системный Win32 API Windows (`SetDeviceGammaRamp`). Для операционной системы и античита это аналогично нажатию физической кнопки яркости на самом корпусе монитора или работе Windows Night Light / f.lux.

## Быстрый старт

1. Скачайте [RustGammaPro.exe](https://github.com/helliong/rust-gamma/releases).
2. Запустите файл — откроется окно настроек:
   - Выберите желаемую гамму (рекомендуется `1.45 – 1.60`).
   - Нажмите **Проверить (2 сек)**, чтобы оценить картинку.
   - Нажмите **Сохранить и свернуть в трей**.
3. Зайдите в Rust и нажимайте `F11` при наступлении ночи.

## Горячие клавиши по умолчанию

| Действие | Горячая клавиша | Звуковой сигнал |
| :--- | :---: | :---: |
| **Режим ночи (Гамма 1.5)** | `F11` | Высокий тон (900 Гц) |
| **Режим дня (Гамма 1.0)** | `F11` | Низкий тон (450 Гц) |

*Клавишу можно переназначить в окне настроек (F10, F9, F8, NumPad *, Scroll Lock и др.).*

## Сборка из исходников

Проект написан на C# (.NET Framework 4.0+) без внешних зависимостей. Для сборки не требуется Visual Studio — достаточно встроенного в Windows компилятора `csc.exe`:

```cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /win32icon:app.ico /r:System.dll,System.Drawing.dll,System.Windows.Forms.dll /out:RustGammaPro.exe RustGamma.cs
```
